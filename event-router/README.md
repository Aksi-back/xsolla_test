# event-router

Роутер биллинговых событий в MMP. Учебная модель: всё в памяти, внешних зависимостей нет.

## Запуск

Нужен Go 1.22+ (https://go.dev/dl/).

```bash
go test ./...          # тесты
go run ./cmd/router    # прогнать testdata/events.json и посмотреть, что ушло в MMP
```

## Структура

| Путь | Что это |
|------|---------|
| `internal/event` | Модель биллингового события |
| `internal/store` | Настройки проектов, маппинги пользователей в MMP, согласия (в проде — MySQL) |
| `internal/sender` | Отправка в MMP. Здесь фейк: запоминает, что отправлено |
| `internal/router` | Логика: что и с каким статусом отправить |
| `cmd/router` | CLI: читает `testdata/`, печатает статусы |
| `testdata/` | Проекты, маппинги, согласия и пример выгрузки событий |

## Термины

- **CUID** (`user_id`) — SHA256 от email пользователя. Общий идентификатор у нас, платёжки и MMP.
- **Маппинг** — связка CUID ↔ идентификатор пользователя в MMP для конкретного приложения (`app_id`). Без маппинга MMP не поймёт, чей это платёж.
- **Статусы** — см. константы в `internal/router/router.go`.
